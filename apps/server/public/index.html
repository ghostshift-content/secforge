IDOR in Checkout order lookup

What happens
OrdersController#show loads an order by params[:id] behind authentication but never checks that the order belongs to the current user. Any authenticated customer can read any other customer's order — line items, address, card last-4.
Vulnerable source · snapshot a1b2c3
app/controllers/orders_controller.rb
40  def show
41    @order = Order.find(params[:id])  # ← no owner scope
42    render json: @order
43  end
Remediation
- @order = Order.find(params[:id])
+ @order = current_user.orders.find(params[:id])

ACX-15
Object read without ownership scope
→ CWE-639, CWE-284
Invariant / goal
A record read for an actor must be constrained to records that actor is authorised to see.
Attacker control
The object identifier in the request path or body, freely chosen by any authenticated actor.
Guard-to-sink differential
Authentication proves who, but the query binds the id with no owner predicate before the read.
Required proof
A production route reaching the read, an actor with no relationship to the object, and the object returned.
Decisive rejection
The query is already owner-scoped (current_user.orders), or a policy check gates the id.
